# My Portfolio Site

This repository contains the a github backup of the code for deploying my personal portfolio site, it is currently self hosted on a raspberry pi at my home through yunohost but was previously hosted on godaddy, netlify and AWS using amplify.
Development

This project uses a React frontend. Prerequisites/Required Tools:

Node.js (v16+) and npm - For React frontend
Git - Version control

Deployment

The website currently uses yarn to build and deploy the website
